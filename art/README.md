# 그림 파이프라인

## 요청 (Claude → 인스턴스)

`art/requests/<이름>.txt` 파일 하나가 그림 한 장이다. 내용은 그림 설명 문장이다.

- 이름은 영어 소문자, 숫자, `_`, `-`만 쓴다. 예: `unpaid_bill_portrait.txt`
- 실제 프롬프트는 `art/style.txt` + 요청 문장으로 합쳐진다.
- 다시 뽑고 싶으면 `art/raw/<이름>.*`을 지우거나 새 이름(`_v2`)으로 요청한다.
- `_`로 시작하는 이름은 파이프라인 시험용이다.

## 결과 (인스턴스 → Claude)

- `art/raw/<이름>.jpg` 원본 그림 (1024×1024)
- `art/raw/<이름>.json` 생성 기록 (대화 ID, 걸린 시간, 프롬프트 해시)
- `art/raw/<이름>.error.txt` 3번 연속 실패하면 남는 오류 기록. 지우면 다시 시도한다.

## 가공 (Claude)

배경 제거, 크기 조정, 게임 규격 맞추기를 거친 그림은 `art/processed/`에 둔다.
