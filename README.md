# Lob

로보토미 코퍼레이션(PC, Unity) 확장팩 모드. 새 환상체 40~50개(등급별 8~10개)와 규칙 자체가 독특한 관리 방법을 추가한다.

## 작업 흐름

1. Claude가 기획, XML, C# 코드, 그림 프롬프트를 이 저장소에 올린다.
2. 인스턴스(Ubuntu 24.04)의 스크립트가 새 프롬프트를 감지해 agy로 그림을 생성하고 다시 올린다.
3. Claude가 그림을 게임 규격에 맞게 다듬고 모드 DLL을 빌드한다.
4. 사용자가 PC에서 완성본을 받아 게임에서 확인한다.

## 주의

- 게임 원본 파일(`Assembly-CSharp.dll` 등)은 이 저장소에 올리지 않는다.
